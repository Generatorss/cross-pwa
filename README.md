# Cross PWA

PWA для кроссовых журналов кабельных соединений.
Стек: Vue 3 + TypeScript + Vite + Dexie + PocketBase.

## Настройка и запуск

1. `npm install`
2. Скопируйте `.env.example` в `.env` и укажите адрес PocketBase-сервера:

   ```
   VITE_PB_URL=https://debian-server:8090
   ```

3. `npm run dev` — режим разработки; `npm run build` — production-сборка в `dist/`.

Без заданного `VITE_PB_URL` приложение работает только офлайн: на экране входа
появится предупреждение, а попытки синхронизации завершатся понятной ошибкой.

## PocketBase

- Версия 0.40.x. Миграции из `pb_migrations/` применяются автоматически при
  старте сервера: положите каталог `pb_migrations/` рядом с исполняемым файлом
  PocketBase и запустите `./pocketbase serve`.
- Роли пользователей задаются полем `role` коллекции `users`
  (viewer / editor / admin): viewer — только просмотр, editor — создание и
  редактирование, admin — дополнительно удаление (включая каскадное).

## Синхронизация

- Все изменения сначала пишутся в локальную базу (IndexedDB/Dexie) и попадают
  в очередь `outbox`; отправка на сервер — при синхронизации.
- Автосинхронизация: при появлении сети, при возврате на вкладку, по таймеру
  раз в минуту (если есть неотправленные изменения), при попытке закрытия
  страницы (best-effort) и сразу после входа.
- Ручной запуск: кнопка «Синхронизировать» на экранах или чип
  «Онлайн» в шапке. Жёлтый бейдж показывает число неотправленных изменений.

## Структура данных

Иерархия: Объект → Шкаф → Стойка → Бокс → Плинт → Пара (пары создаются
автоматически при добавлении плинта, сквозная нумерация в боксе).

- Кроссовые соединения (`cross_connections`): пара ↔ пара (с выбором провода
  A/B на каждой стороне) или пара ↔ внешний кабель (`to_foreign_cable_name`),
  с типом соединения, привязкой к линии и описанием. Редактор — на карточке
  пары.
- Линии (`lines`) — сквозные логические цепи через несколько объектов.
- Неисправности (`faults`) — привязываются к паре, провод A/B, тип из
  справочника `fault_types`, статус active/resolved.
