# Техническое задание. Вариант 1 (стандартное изложение)

**Система:** Учёт кабельных линий и кроссовых подключений.
**Статус:** проект для согласования. Версия 1.0.
**Дата:** 18.11.2026.
**Основание:** описания Заказчика и ответы на вопросы (v0.1–v0.2). Документ заменяет прежние версии.

**Изменения относительно v0.2:**
1. Заглушка и грозозащита введены как самостоятельные сущности.
2. Определены состояния пары: элемент разъёмника и проводимость.
3. Размыкание/замыкание при измерениях отнесено к журналу измерений. Журнал операций — только изменения подключений и элементов разъёмника.
4. Изложение переработано: краткие однозначные формулировки.

---

## 1. Общие сведения

1.1. Система предназначена для учёта кабельной инфраструктуры и кроссовых подключений.
1.2. Учёт охватывает: объекты; кроссовые шкафы и оборудование; кабельные трассы; маршруты прокладки; подключения; линии; неисправности; журналы; схемы.
1.3. Приложение работает офлайн. Данные синхронизируются с сервером при появлении связи.
1.4. Реализовано: иерархия «объект — пара»; кроссировки; внешние провода; роли; каскадное и массовое удаление; синхронизация.

## 2. Термины и определения

| Термин | Определение |
|---|---|
| Объект | территориальный пункт размещения кроссового оборудования |
| Шкаф | кроссовый шкаф на объекте; содержит стойки |
| Стойка | конструктив шкафа; содержит боксы |
| Бокс | монтажный блок стойки; содержит плинты |
| Плинт | модуль коммутации; содержит пары; типовое число пар — 10 |
| Пара | коммутационная единица плинта; вмещает две жилы кабеля: А и Б |
| Верхние контакты пары | кабельная часть; к ним подключены жилы кабеля |
| Нижние контакты пары | кроссировочная часть; к ним подключают кроссировки и оборудование |
| Разъёмник | разъёмное соединение в середине пары |
| Сквозное соединение | замкнутое состояние разъёмника; состояние по умолчанию |
| Заглушка | изоляционный элемент разъёмника; размыкает пару на длительный срок |
| Грозозащита | защитный элемент разъёмника; сохраняет сквозное соединение |
| Кроссировка | два свитых проводка; соединяет нижние клеммы двух пар одного шкафа |
| Трасса | один кабель между двумя объектами |
| Муфта | точка ремонта кабеля на маршруте |
| Кольцо запаса | запас кабеля на маршруте |
| Колодец связи | подземная точка маршрута |
| Линия | сквозное соединение «устройство — устройство» через кроссы и кабели |
| Неисправность | зарегистрированный дефект жилы или пары |

## 3. Роли и права доступа

3.1. **admin** — полный доступ, включая удаления.
3.2. **editor** (техник) — создание и правка оперативных данных. Удаления запрещены.
3.3. **viewer** (стажёр) — только просмотр.
3.4. Правило распределения: справочники и структура сети — admin; оперативные данные — editor и admin; удаление любых записей — admin.

## 4. Классы данных

| Класс | Состав | Режим изменений |
|---|---|---|
| Структура сети («константы») | объекты, трассы, маршруты, шкафы, стойки, боксы, плинты, пары, разводка жил | редкие изменения |
| Оперативные данные | кроссировки, включения оборудования, заглушки, грозозащита, линии, неисправности, журналы | постоянные изменения |

## 5. Справочники

| Справочник | Состав |
|---|---|
| Типы кабелей | название. Примеры: кабель связи, витая пара |
| Марки кабелей | марка; тип; типовое число жил |
| Модели шкафов | марка; размеры; материал изготовления |
| Модели плинтов | марка; число пар (по умолчанию 10); тип клемм: автозажим, под болт |
| Типы прокладки | название. Примеры: труба бетонная 200 мм; грунт; ГНБ |
| Типы неисправностей | замыкание; обрыв; низкое сопротивление изоляции; наводки |

## 6. Кроссовая иерархия

6.1. Иерархия: объект → шкаф → стойка → бокс → плинт → пара.
6.2. Каждый уровень имеет наименование или номер и привязку к верхнему уровню.
6.3. Шкафы и плинты привязываются к моделям из справочников.

## 7. Физическая модель пары

7.1. Пара вмещает две жилы кабеля: жила А, жила Б.
7.2. Контакты пары: два верхних, два нижних.
7.3. Жилы кабеля подключены к верхним контактам.
7.4. Кроссировки и оборудование подключаются к нижним контактам.
7.5. В середине пары установлен разъёмник.
7.6. По умолчанию разъёмник замкнут. Пара имеет сквозное соединение.
7.7. Заглушка размыкает пару. Применяется для длительного отключения линии или оборудования.
7.8. Грозозащита сохраняет сквозное соединение. Устанавливается на каждую пару отдельно.
7.9. В разъёмнике находится один элемент: ничего, заглушка или грозозащита.
7.10. Переключения выполняются только на нижних контактах. Верхние контакты не изменяются.
7.11. Ёмкостный расчёт: 100 жил = 50 пар = 5 плинтов. 100 пар = 10 плинтов.

## 8. Состояние пары

8.1. Состояние пары включает: элемент разъёмника; проводимость.
8.2. Элемент разъёмника: отсутствует (по умолчанию), заглушка, грозозащита.
8.3. Проводимость: замкнута (по умолчанию), разомкнута.
8.4. Установлена заглушка — пара разомкнута.
8.5. Установлена грозозащита или разъёмник пуст — пара замкнута.
8.6. Состояние отображается в списках пар и в кроссовом журнале.

## 9. Кабельные трассы

9.1. Один кабель — одна трасса.
9.2. Название трассы: «Объект 1 — Объект 2». Формируется автоматически.
9.3. Атрибуты: тип кабеля; марка; исходное число жил; текущее число жил.
9.4. Трасса имеет два конца. Каждый конец заводится в кроссовый шкаф.
9.5. Концы обычно расположены на разных объектах.
9.6. Разводка: жила → пара конкретного плинта. Регистрируется для каждого конца.
9.7. Жилы одного кабеля разводятся преимущественно в одну стойку или бокс.
9.8. Ремонт кабеля: добавляется муфта. Число жил может измениться: 100 → 80; 80 → 100, из них 20 запасных.

## 10. Маршрут трассы на карте

10.1. Карта работает офлайн. Тайлы обновляются при появлении связи.
10.2. На карте отображаются: объекты; линии трасс; колодцы; муфты; кольца запаса.
10.3. Точка маршрута: тип; координаты; фото; примечание. Типы: объект, колодец связи, муфта, кольцо запаса, промежуточная точка.
10.4. Муфта: координаты; фото; дата ремонта; исполнитель; тип муфты.
10.5. Сегмент маршрута: точка начала; точка конца; тип прокладки; глубина закладки; примечание; фото.
10.6. Фото: съёмка камерой приложения и загрузка из файловой системы. Выгрузка при появлении связи.

## 11. Подключения и элементы разъёмника

11.1. Кроссировка: два свитых проводка. Соединяет нижние клеммы двух пар. Выполняется только внутри одного шкафа.
11.2. Оборудование, основной вариант: заводится в шкаф на отдельный плинт. Плинты соединяются кроссировкой.
11.3. Оборудование, допустимый вариант: прямое включение в нижние клеммы пары.
11.4. Заглушка — сущность. Атрибуты: пара; тип; дата установки; исполнитель; дата извлечения.
11.5. Грозозащита — сущность. Атрибуты: пара; тип; дата установки; исполнитель; дата снятия.

## 12. Линии

12.1. Линия — сущность. Соединяет устройства через всю инфраструктуру.
12.2. Путь линии: устройство → внешнее включение → пары → кроссировки → кабели → шкафы → объекты → устройство.
12.3. Путь строится автоматически обходом графа подключений.
12.4. Просмотр линии показывает все элементы пути: объекты, шкафы, стойки, боксы, плинты, пары, кабели, муфты, устройства.
12.5. Одна линия может обслуживать несколько устройств. Параллельные включения учитываются списком устройств линии.
12.6. Разомкнутая пара на пути линии — признак разрыва. Отображается в карточке линии.

## 13. Журнал операций

13.1. Назначение: фиксация всех изменений подключений и элементов разъёмника.
13.2. Типы операций:
- подключение кроссировки;
- отключение кроссировки;
- переключение кроссировки;
- подключение оборудования;
- отключение оборудования;
- вставка заглушки;
- извлечение заглушки;
- установка грозозащиты;
- снятие грозозащиты;
- ввод начальных данных.
13.3. Атрибуты записи: тип операции; дата и время; ФИО техника; объект, шкаф, плинт, пара; состояние «было»; состояние «стало»; примечание.
13.4. Дату и время задаёт пользователь. По умолчанию применяется установленное вручную значение или текущее.
13.5. Записи не удаляются и не редактируются. Хранение бессрочное.
13.6. Начальное заполнение: массовый ввод существующих подключений с типом операции «ввод начальных данных».

## 14. Журнал измерений

14.1. Назначение: фиксация измерений характеристик кабелей и пар.
14.2. Размыкание и замыкание разъёмника при измерениях фиксируются в этом журнале.
14.3. Атрибуты: дата; объект измерения; параметры; результат; прибор; техник.
14.4. История измерений хранится по каждой паре.
14.5. Реализуется на последнем этапе. Включает отчёты, формы вывода и печать.

## 15. Кроссовый журнал объекта

15.1. Формируется отдельно для каждого объекта.
15.2. Структура: шкафы объекта → плинты → таблица пар.
15.3. Графы пары: номер; жилы кабеля (марка, номер пары кабеля); нижнее включение (кроссировка, оборудование, свободно); элемент разъёмника; проводимость; неисправности.
15.4. Предусмотрен вывод на печать.

## 16. Неисправности

16.1. Типы — из справочника.
16.2. Привязка: жила; пара; пара кабеля; трасса; линия.
16.3. Атрибуты: параметры; примечание; статус (открыта, устранена); исполнитель; даты регистрации и устранения.
16.4. Отображение: карточка пары; кроссовый журнал; карточка линии; своды по объекту и трассе.

## 17. Схемы

17.1. Схема сети: все объекты и трассы. Атрибуты: типы, марки, число жил, муфты, координаты. Свод по неисправностям.
17.2. Схема трассы: маршрут с сегментами; колодцы; муфты; кольца; фото; точки подключения концов кабеля.
17.3. Схема линии: полный путь линии; оконечные и параллельные устройства.

## 18. Интерфейс

18.1. Разделы: карта; объекты; трассы; линии; журналы; неисправности; справочники; схемы; измерения и отчёты; настройки.
18.2. Разделы «измерения и отчёты» и «настройки» реализуются на последнем этапе.
18.3. Списки пар отображают: кабельную часть, нижнее включение, элемент разъёмника, проводимость.
